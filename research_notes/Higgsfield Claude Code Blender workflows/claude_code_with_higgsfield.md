## 1. What has Higgsfield officially published about its MCP server / Claude connector?

### Takeaway
The official connector is a hosted MCP at `https://mcp.higgsfield.ai/mcp` that signs in to an existing paid Higgsfield account by OAuth and bills the plan's credits; it now carries far more than generate calls: named slash recipes, bundled SKILL.md workflows, cost-quote tools, an Editing Room timeline, 3D/Blender scene tools, and a cloud Linux sandbox with ffmpeg and headless Chromium that can return frames to the model for inspection. Higgsfield's stated preference for coding agents is the CLI plus its skills repo, there is no native spend cap, and "Unlimited" plan allowances are reported not to apply through MCP; the original launch date could not be confirmed from a primary source.

**Cloud sandbox (first-party, read in this session)**
- `sandbox_exec` runs shell commands "in a remote Higgsfield cloud Linux sandbox — NOT your local machine". Preinstalled: ffmpeg/ffprobe, ImageMagick, sox, python3 with Pillow and faster-whisper, node/npm/npx, sharp-cli, Playwright with headless Chromium, caption fonts (Metropolis, Montserrat), zip, git, curl, jq. [IN-SESSION] — [Higgsfield MCP: sandbox_exec](https://mcp.higgsfield.ai/mcp)
- Limits: commands time out after 60 s by default (max 120); `background:true` for longer work with a 15-minute execution limit, polled through log/status files; `/home/user` persists for 24 hours since last use; processes and RAM do not survive replacement; `size:"xl"` only for the heaviest CPU work such as a final multi-job render. [IN-SESSION] — [Higgsfield MCP: sandbox_exec](https://mcp.higgsfield.ai/mcp)
- Visual inspection: pass `image_paths` (up to 4 PNG/JPEG, 512 KiB total) with a foreground command and "images are returned natively to the model, not as text or URLs"; the parameter note says "Inspect the actual images before writing visual review verdicts." [IN-SESSION] — [Higgsfield MCP: sandbox_exec](https://mcp.higgsfield.ai/mcp)
- Getting outputs out: call `media_upload` before the producing command, append a `curl -f -X PUT ... --upload-file` to the same command, then `media_confirm` after HTTP 200. Workflow bundle scripts are preinstalled under `$HF_WORKFLOWS` (`/home/user/.higgsfield/workflows/<workflow>/scripts/...`). [IN-SESSION] — [Higgsfield MCP: sandbox_exec](https://mcp.higgsfield.ai/mcp)

### Inferences
- For a Claude Code cloud session with the connector attached, the lowest-waste opening sequence implied by the first-party text is: `balance` → `get_workflow_instructions` (no argument) to see whether a bundled workflow already covers the job → `models_explore` for the chosen model's exact params and media roles → `estimate_*_cost` → show the quote → generate by `quote_ref`. None of the read/quote steps is described as costing credits.
- The sandbox makes a hybrid pipeline possible entirely inside the connector: generated clips can be pulled in by result URL, cut and composited with ffmpeg, rendered from HTML with headless Chromium, and frames returned to the model for review. No public write-up of people doing this through `sandbox_exec` was found; the capability is documented only in the tool description.
- The "Unlimited" position looks inconsistent across sources: the help centre says MCP always deducts credits, while trial promotions and the `use_unlim` parameter show that free-trial unlimited generation does exist on MCP. The likely reading is that only trial allowances apply, not plan-level Unlimited; this is not confirmed.
- Third-party skills written before autumn 2026 are drifting from the live tool surface (`get_cost` flag, `job_status`, `presets_show`, `create_character` are named in older guides but do not match the tool names visible now).

## 2. What third-party Claude skills or agent guides exist for Higgsfield, and what do they tell the agent to do?

### Takeaway
There are four distinct families: Higgsfield's own `higgsfield-ai/skills` (CLI-driven, the actively maintained baseline), a large community prompt-construction library from O-Side Media (now archived, with the "vibe-motion", "stack" and "pipeline" sub-skills listed on skills.sh), a small MCP-wrapper skill from RoboNuggets whose value is a mandatory cost gate and measured gotchas, and Playwright browser-automation packs that click through the Higgsfield website. The MCP-wrapper and prompt-library skills contain the most reusable instructions; the Playwright packs are brittle and have no cost controls.

## 3. What end-to-end examples exist of Claude or Claude Code producing a finished video with Higgsfield?

## 4. How do people combine Claude Code with Remotion, HyperFrames, ffmpeg or Descript, using a video model only for hard shots?

### Takeaway
The common division of labour is: the video model makes only short picture-only B-roll or hero shots; everything deterministic (cuts, captions, titles, zooms, split-screens, grain, audio levels, final render) is code that Claude Code writes and re-renders for free. Remotion and HyperFrames both ship official agent skills, several open skill repos package the whole hybrid pipeline with paid-call gates and frame-based QC, and the Higgsfield connector itself now offers a hosted ffmpeg/Chromium sandbox and montage/sound-design workflows.

## 6. What limitations and failure modes do people report when an agent drives video generation, and what review loops or guardrails do they use?

### Takeaway
The recurring problems are that the agent cannot watch video, the platform has no spend cap while retries are the real cost, and model or tool quirks fail silently (wrong parameter keys, plan-gated models, default durations, false moderation flags). The working guardrails are a quote-then-approve gate on every paid call, stills and a single test clip before any batch, frame extraction or contact sheets that the model actually looks at, small batches, a lessons file, and a declared lock after which nothing is regenerated.

### Cited Findings

**The agent cannot watch the output**
- Claude's uploads take documents and images, not video or audio; the workaround is frames plus a transcript, and Claude Code can run ffmpeg locally to pull frames and audio. [SEARCH SUMMARY] — [creativeclaw.co](https://creativeclaw.co/claude/watch-videos/)
- Frame check rule in a working skill: extract frames from every generated clip with ffmpeg and inspect them; "Verify frames, trust pixels over labels"; single-frame command `ffmpeg -ss T -i clip.mp4 -frames:v 1 out.png`. [OPENED] — [reel-studio references/higgsfield.md](https://github.com/harper-carroll/reel-studio-skill/blob/main/reel-studio/references/higgsfield.md)
- Contact-sheet QC: `review.py` extracts a frame contact sheet from each clip, Claude scores it on prompt fidelity, consistency, motion and audio, appends a one-line cause-and-effect lesson to `LESSONS.md`, and step 0 of every later workflow reads that file back ("Every generation ends with a quality-control pass"). [OPENED] — [0xadvait/ai-video-skill](https://github.com/0xadvait/ai-video-skill)
- Technical checks that need no eyes: ffprobe-style checks of streams, duration, codec, audio, resolution and black frames; layout contact sheets for caption and lower-third collisions. [OPENED] — [Bomx/OpenVideo](https://github.com/Bomx/OpenVideo)
- Higgsfield-side review options: the sandbox returns up to 4 images per call natively to the model for inspection; `video_analysis_create` gives a scene-by-scene analysis or answers a question about an uploaded video, costs credits, takes 3 to 5 minutes on average, has a cheaper `glance` mode, and gets less accurate as the video gets longer. [IN-SESSION] — [Higgsfield MCP tool descriptions](https://mcp.higgsfield.ai/mcp)

**Cost run-ups**
- Guides warn that each Higgsfield video call costs roughly 30 to 60 credits and an autonomous agent in a loop can burn through a free tier in about five minutes; advice is not to auto-approve the generation tool. Which guide carries those exact figures was not confirmed. [SEARCH SUMMARY] — [roborhythms: Connect Higgsfield MCP to Claude Before Video Eats Your Credits](https://www.roborhythms.com/connect-higgsfield-to-claude/); [vibetoolstack: Don't-Burn-Credits System](https://vibetoolstack.com/blog/higgsfield-mcp-setup-guide)
- There is no spending cap on the Higgsfield side; the suggested workaround is to state a per-session credit limit in the conversation. [SEARCH SUMMARY] — [Layer3 Labs: Higgsfield MCP Setup and the Credit Catch](https://www.layer3labs.io/guides/higgsfield-mcp)
- Unlimited tiers and free generations are reported to apply only in the browser interface, not through MCP, CLI, Canvas or Supercomputer. [SEARCH SUMMARY] — [aituber.app](https://aituber.app/blog/higgsfield-mcp-video-generation/)
- Retries dominate: one community library budgets on acceptance rates of 1.0% for images and 1.5% for video, working out to about 67 attempts per keeper and roughly 1,000 credits per finished shot for Kling 3.0 at 8 s (16 credits each). These are the author's planning benchmarks, far more pessimistic than the B-roll write-ups, and not independently verified. [OPENED] — [higgsfield-stack SKILL.md](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/blob/main/skills/higgsfield-stack/SKILL.md)
- Reported per-generation credit figures (all third-party, all dated, all different): Kling 3.0 about 6 at 4K; Wan 2.7 about 9 per 6 s at 1080p; Gemini Omni about 21 per 7 s; Seedance 1.5 480p about 2.4 for 4 s and 7.2 for 12 s; GPT Image 2 about 3; Nano Banana 2 about 11; Kling 3.0 8 s std 16. [OPENED] — [reel-studio references/higgsfield.md](https://github.com/harper-carroll/reel-studio-skill/blob/main/reel-studio/references/higgsfield.md); [robonuggets SKILL.md](https://github.com/robonuggets/higgsfield-skill/blob/main/.claude/skills/higgsfield/SKILL.md); [higgsfield-stack SKILL.md](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/blob/main/skills/higgsfield-stack/SKILL.md)

**Silent failures and platform quirks**
- Plan tier can silently block premium models (the example given is `seedance_2_0` returning a generic error); check balance and tier before debugging the prompt. Seedance 1.5 defaults to 12 seconds if `duration` is omitted, three times the cost of 4 seconds, so always set it. Skipping `select_workspace` makes generation calls fail silently. [OPENED] — [robonuggets SKILL.md](https://github.com/robonuggets/higgsfield-skill/blob/main/.claude/skills/higgsfield/SKILL.md)
- The resolution key differs by model (`resolution` or `quality`): "Passing the wrong key silently falls back to default." Dark, silhouette or abstract clips can be falsely flagged NSFW. A moody prompt may return a `preset_recommendation` instead of a job; resend with `declined_preset_id` to run the literal prompt. More than about five simultaneous `generate_video` calls triggers `429 rate_limit_reached`. Clips take roughly 1 to 3 minutes. The MCP cannot read local paths. [OPENED] — [reel-studio references/higgsfield.md](https://github.com/harper-carroll/reel-studio-skill/blob/main/reel-studio/references/higgsfield.md)
- Server-defaulted parameters (for example `mode=std`, `sound=on`) can appear in an `adjustments` block on a cost response and should be shown to the user; plausible-looking parameter names can be invalid. [OPENED] — [higgsfield-stack SKILL.md](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/blob/main/skills/higgsfield-stack/SKILL.md)
- Live connector warnings: "On a transport timeout the submission outcome may be unknown: do not automatically resubmit"; "A quote does not validate that the request is ready to generate"; a rejected free or unlimited request must not be retried on credits without explicit approval. [IN-SESSION] — [Higgsfield MCP: generate_video](https://mcp.higgsfield.ai/mcp)
- Quality failure modes listed for multi-clip work: animating a "good enough" image instead of fixing the hero frame; inconsistent character wording across prompts; no prop sheet, so objects drift; describing character age in Seedance prompts (called unreliable); scenes over 15 seconds, where prompt adherence degrades; chain drift around the 4th or 5th chained generation; resolution mismatch between source and extension; over-engineering single clips with the full pipeline. [OPENED] — [higgsfield-pipeline SKILL.md](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/blob/main/skills/higgsfield-pipeline/SKILL.md)

**Weak taste**
- Generic generated visuals are named as the failure to avoid: "generic people at laptops, glowing AI brains, neon grids, and floating icons"; real screenshots and source material are preferred over generated B-roll. [OPENED] — [Bomx/OpenVideo](https://github.com/Bomx/OpenVideo)

**Guardrails people use**
- Quote-then-spend: quote model, settings, estimated credits, current balance and balance after; wait for explicit approval; "Auto mode does not bypass this." [OPENED] — [robonuggets SKILL.md](https://github.com/robonuggets/higgsfield-skill/blob/main/.claude/skills/higgsfield/SKILL.md)
- Make the paid step opt-in with a default of no, state the model, the credit budget and the exact ask, and re-quote image-to-video separately from text-to-video. [SEARCH SUMMARY] — [ceos3c](https://www.ceos3c.com/ai/higgsfield-mcp/)
- "Preview cheap, commit late": style samples as single images, cost check, one test clip before a batch, one rendered still before a full render; confirm the shot list before spending. [OPENED] — [reel-studio SKILL.md](https://github.com/harper-carroll/reel-studio-skill/blob/main/reel-studio/SKILL.md)
- Paid-call gate listing providers, count, duration, resolution and cost drivers: "Pause before paid HeyGen/OpenAI/Replicate calls and show me the plan first." [OPENED] — [Bomx/OpenVideo](https://github.com/Bomx/OpenVideo)
- Validate the request against the model schema before every spend; re-run clips only when asked. [OPENED] — [0xadvait/ai-video-skill](https://github.com/0xadvait/ai-video-skill)
- Fix in the cheapest medium: repair identity drift with an image edit rather than a re-roll; treat caption, split and timing changes as code edits; declare picture lock, after which "there are no new generations". [OPENED] — [higgsfield-pipeline SKILL.md](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/blob/main/skills/higgsfield-pipeline/SKILL.md)
- Keep a spend ledger (`log-gen`, `ratio`, `budget`) and, for tools with no cost field, check balance before and after. [OPENED] — [OSideMedia/higgsfield-ai-prompt-skill](https://github.com/OSideMedia/higgsfield-ai-prompt-skill)
- Show the human an edit list before cutting, never overwrite sources, and commit a version after each approved cut. [OPENED] — [vargHQ/skills how-to](https://github.com/vargHQ/skills/blob/main/how-to/edit-video-with-claude-code/README.md)
- Failed generations are reported as refunded in credits. [SEARCH SUMMARY] — [IT-Connect](https://www.it-connect.tech/how-i-created-cybersecurity-awareness-videos-with-claude-and-higgsfield/)

### Inferences
- Frame sampling catches composition, identity, text artefacts and false moderation flags, but not motion quality, temporal flicker, lip-sync or audio. None of the sources claims an agent-only loop is sufficient for those; every documented process keeps a human viewing step before a batch and before delivery.
- Because quotes are free and generation is not, the cheapest reliable control is structural: one file listing every planned paid call with its quoted cost, approved as a batch, then executed by quote reference so what runs is exactly what was approved.
- Per-credit figures in public skills disagree by an order of magnitude across models and dates, so any hard-coded cost table should be treated as stale; the live estimate tools are the only trustworthy number.
- Skills written against earlier connector versions can themselves be a failure source (obsolete tool names and flags). A skill for this connector should tell the agent to read the live tool descriptions and workflow instructions first.

### Gaps
- No Reddit or X threads with first-hand accounts of credit run-ups or agent failures were retrieved; the cost warnings come from setup-guide blogs, several of which appear affiliate-driven.
- No source quantified how often frame-only review misses a motion defect, or gave a measured acceptance rate from a real project (the 1.0% and 1.5% figures are one author's planning anchors).
- The exact attribution of the "30 to 60 credits per video call" figure and of the "slow re-render" Vibe Motion complaint could not be pinned to a single page.
- Current official per-model credit prices were not obtained; `models_explore` is reported not to return prices, and the estimate tools were not called.
