# BuddhandBeyond

A static website about Buddhist teachings and meditation, plus video work for it made with
Higgsfield.

## Video work

Read `notes/video-production-notes.md` before making any image or video. It holds the user's
taste, what has been made and how it was rated, current credit prices, and where to use code
instead of a paid video model.

Rules that always apply:

- State the credit cost before any video render and wait for a yes.
- Render one take. Do a second only when asked or when the first has a visible fault.
- Use code (Remotion, or ffmpeg and a headless browser) for zooms, cuts, compositing, text and
  sound. Pay a video model only for organic motion: morphs, fluids, characters, physics.
- Check results with frame strips before showing them, and say what could not be checked.
- Update the notes file after each piece: method, cost, and the user's rating.
